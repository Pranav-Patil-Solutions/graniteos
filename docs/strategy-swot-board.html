Net: ~6 strongly habit-forming · 2 conditional · 2 at-risk. Hooks best where there's daily money pain (udhaar) + few alternatives; worst where users are too advanced or too low-tech/disconnected.

✅ Where the hook fires

  1. Udhaar is the killer trigger — every owner obsesses over who owes money; surfaced first.
  2. Streak + confetti make a back-office tool genuinely rewarding to open.
  3. Role-aware briefing forms the habit across the whole team, not just the owner.
  4. Catalogue + WhatsApp create an external pull ("did they see it?").

⚠️ Where it leaks (churn)

  1. Month-1 onboarding cliff — heavy data entry before the first reward. #1 churn point.
  2. Cold start — streak/celebration only feel good once data + real payments exist.
  3. Streak is localStorage-only — resets on new device; the investment leaks (flagged "v1").
  4. Push not yet real — trigger depends on the user remembering to open.
Complete SWOT

🟢 Strengths

  1. Vertical depth rivals lack — block→slab, sq-ft/running-ft, recovery wedge, 3D+AR catalogue.
  2. GST done right — Rule-46 invoice, CGST/SGST/IGST, HSN/UQC, FY numbering, paise-accurate.
  3. Designed-in habit loop — briefing → do-now → celebration → streak. Rare in SMB ERP.
  4. Mobile + WhatsApp + UPI native — matches how Indian traders actually work.
  5. Udhaar as the spine — the one number checked daily, surfaced first.
  6. Multi-tenant, RLS, role-aware + premium brand (made by HandelOS).

🔴 Weaknesses

  1. Onboarding friction — steep first-week data hill; no guided setup / photo capture.
  2. Streak & "last seen" localStorage-only — don't survive devices.
  3. Push notifications not yet real — half the hook unproven.
  4. Single-company / single-location — no multi-outlet, no inter-branch transfer.
  5. Manufacturer depth gaps — no BOM, batch wastage, project/BOQ.
  6. Supplier side thin; place-of-supply intra default; no data-export story yet.

🟡 Opportunities

  1. Receivables → financing — reminders, then invoice financing on proven udhaar.
  2. Vernacular + voice + offline — unlock the rural/low-tech long tail.
  3. WhatsApp as the trigger channel — deliver the briefing where they live.
  4. Stone Finder AI + AR catalogue — novel lead-gen; the showroom hook.
  5. Slab Bazaar — cross-tenant idle-slab exchange = network effects.
  6. CA/GSTR export + benchmarks — turn the accountant into an advocate.

⚠️ Threats

  1. Tally/Vyapar incumbency + accountant lock-in — "my CA uses Tally."
  2. Habit loop can feel gimmicky to no-nonsense older owners.
  3. Connectivity/literacy caps the addressable base without offline+vernacular.
  4. Data-trust & DPDP — a breach or "they have my customer list" fear kills trust.
  5. Fast-follower — Vyapar could add a "stone pack"; defend with habit + brand.
  6. Platform dependence — WhatsApp/UPI policy; single-Supabase fragility.

The three sharpest moves

  1. Win the first week or lose the user — guided setup, sample data, snap-a-slab / WhatsApp-assisted import. Highest-ROI fix.
  2. Make the trigger real & durable — deliver the briefing via WhatsApp; move streak/last-seen to the server.
  3. The udhaar loop is the moat — deepen it — reminders → financing → benchmarks. The one ritual every persona shares.
Grounded in the shipping app: briefing.ts (role-aware daily briefing), StreakChip, CelebrationLayer, party ledger, GST invoicing, AR/3D catalogue.
